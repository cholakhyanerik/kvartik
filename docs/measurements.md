# Замеры Kvartik

История замеров Правила 1 ([CLAUDE.md](../CLAUDE.md)): размер wasm и время
первого захода по выпускам, с датой, устройством, браузером и версией. Цели
и выводы из этих чисел — в самом правиле; здесь — откуда они взялись.

**Сравнивать новый замер можно только с замером на том же устройстве и тем
же способом**, а две сборки — в один день одним скриптом: сценарий
`measure` skill `browser-run` (`.claude/skills/browser-run/`), он же
описывает способ. Новый замер дописывается в конец списка — версия, дата,
что изменилось, числа и способ.

Устройство всех записей, если не сказано иное: AMD Ryzen 7 260, Windows 11,
headless Chrome 155; «телефон» — эмуляция по образцу Lighthouse (RTT
562,5 мс, 1,47 Мбит/с, процессор ×4, 412×823).
